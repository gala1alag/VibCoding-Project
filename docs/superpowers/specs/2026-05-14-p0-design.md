# P0 功能设计文档

## 项目管理模块

### UI
- 顶部工具栏：添加按钮 + 搜索框
- 卡片网格：每张卡片显示项目名、语言徽章（颜色区分）、路径、最后打开时间、打开按钮、删除按钮
- 支持拖拽文件夹/文件到窗口添加项目

### 语言检测
- 文件夹：统计目录下各扩展名文件数量，取最多的那种
- 单文件：直接看扩展名
- 特殊规则：目录下有 `.pro` 文件 → Qt

### 打开逻辑（按语言映射 IDE）
| 语言 | IDE | 查找方式 |
|------|-----|---------|
| C++ | Visual Studio (`devenv.exe`) | 注册表 + 常见路径 |
| Python | PyCharm (`pycharm64.exe`) | 注册表 + 常见路径 |
| Qt | Qt Creator (`qtcreator.exe`) | 注册表 + 常见路径 |
| 其他 | 系统默认 | `os.startfile()` |

### 数据
- SQLite `projects` 表（已建好）
- 打开时更新 `last_opened_at`

## 快速启动器模块

### UI
- 顶部大搜索框（Tab 切换时自动聚焦）
- 结果列表：图标 + 应用名 + 路径
- 回车或双击启动

### 扫描范围
- 开始菜单（用户 + 系统）：`%APPDATA%\Microsoft\Windows\Start Menu`、`%ProgramData%\Microsoft\Windows\Start Menu`
- 桌面（用户 + 公共）
- `Program Files` / `Program Files (x86)` 下一层 `.exe`
- 解析 `.lnk` 快捷方式获取真实路径
- 后台线程扫描，结果缓存到 `app_index` 表

### 搜索
- `rapidfuzz` 模糊匹配应用名
- 实时过滤（输入即搜，无需回车）

### 启动
- `subprocess.Popen` 启动应用
- 记录使用频率（`last_scanned_at` 更新），后续可按频率排序
